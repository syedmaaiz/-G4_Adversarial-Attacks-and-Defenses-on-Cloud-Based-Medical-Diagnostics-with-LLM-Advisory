Project Explanation: Medical X-Ray Classifier, Adversarial Attack, and Defense

1. What We Implemented First

We first built the normal medical image classification pipeline. This is the foundation of the whole project.

The baseline system does the following:

- Loads the chest X-ray dataset from data/raw/.
- Uses two classes: NORMAL and PNEUMONIA.
- Resizes and normalizes each image so it can be passed into a neural network.
- Splits the original training data into a larger training set and a validation set.
- Keeps the official test set untouched for final evaluation.
- Trains a ResNet18 image classifier using PyTorch.
- Saves the trained model as artifacts/models/baseline_model.pt.
- Reports clean test performance using accuracy, precision, recall, F1-score, and a confusion matrix.

We then improved the baseline training by adding class-weighted loss. This matters because the dataset has many more PNEUMONIA images than NORMAL images. Without weighting, the model becomes biased toward predicting PNEUMONIA. Class weights give more importance to the smaller NORMAL class during training.

After that, we implemented the attack phase using FGSM, then implemented two defenses:

- Defensive randomization: a lightweight preprocessing defense that slightly resizes/smooths inputs.
- Adversarial training: a stronger defense where the model is trained on both clean images and FGSM-attacked images.

2. What Is an Attack in This Project?

An adversarial attack is a small, carefully calculated change to an input image that is designed to fool the neural network.

In our project, the attacker takes a chest X-ray image and adds tiny mathematical noise to it. The goal is not to make the image obviously different to a human. The goal is to change the model's prediction.

For example:

- Clean image: model predicts NORMAL correctly.
- Attacked image: the image looks almost the same, but the model predicts PNEUMONIA.

The attack we implemented is called FGSM, which stands for Fast Gradient Sign Method.

FGSM works by checking how the model's loss changes with respect to the input image. Then it slightly changes the image in the direction that increases the model's error. The size of the change is controlled by epsilon.

In simple terms:

- Small epsilon means a small attack.
- Larger epsilon means a stronger perturbation.
- The attack is successful if a clean-correct prediction becomes wrong after the perturbation.

3. Baseline Model Result

After class-weighted baseline training, the model got this result on the clean test set:

Clean accuracy: 85.74%

Confusion matrix:

[[148, 86],
 [3, 387]]

This means:

- 148 NORMAL images were correctly predicted as NORMAL.
- 86 NORMAL images were wrongly predicted as PNEUMONIA.
- 3 PNEUMONIA images were wrongly predicted as NORMAL.
- 387 PNEUMONIA images were correctly predicted as PNEUMONIA.

The model is very good at detecting PNEUMONIA, but still has some trouble with NORMAL images.

4. What the Attack Metrics Mean

When we evaluated FGSM at epsilon 0.01 on the baseline model, we got:

Clean accuracy: 0.8574
Adversarial accuracy: 0.5369
Prediction change rate: 0.3205
Attack candidates clean-correct: 535
Successful attacks clean-correct-to-wrong: 200
Standard attack success rate: 0.3738

Here is what each metric means.

Clean accuracy:

This is the model's accuracy on the original, unmodified test images.

For the baseline model, clean accuracy was 85.74%.

Adversarial accuracy:

This is the model's accuracy after the FGSM attack is applied to the test images.

For the baseline model, adversarial accuracy dropped to 53.69%.

That drop shows that the model is vulnerable to adversarial examples.

Prediction change rate:

This measures how often the model changed its prediction after the attack, regardless of whether the original prediction was correct.

For the baseline model, prediction change rate was 32.05%.

Attack candidates clean-correct:

This is the number of images the model classified correctly before the attack. These are the meaningful candidates for attack success.

For the baseline model, 535 out of 624 test images were clean-correct.

Successful attacks clean-correct-to-wrong:

This is the number of clean-correct images that became incorrect after the attack.

For the baseline model, 200 clean-correct images became wrong after FGSM.

Standard attack success rate:

This is the most important attack metric. It is calculated as:

successful attacks / clean-correct attack candidates

For the baseline model:

200 / 535 = 0.3738

So FGSM successfully broke 37.38% of the images that the model originally classified correctly.

5. Per-Class Attack Results

For the baseline model at epsilon 0.01:

NORMAL:
clean_correct=148/234
successful_attacks=146
success_rate=0.9865

PNEUMONIA:
clean_correct=387/390
successful_attacks=54

This tells us the attack was much stronger against NORMAL images.

Almost every correctly classified NORMAL image became wrong after attack. PNEUMONIA images were much more stable.

This is important for the report because it shows the model's vulnerability is not evenly distributed across classes.

6. Defensive Randomization Result

Defensive randomization was our first defense. It slightly modifies the image before prediction to try to reduce the effect of adversarial noise.

Best result from the sweep:

Clean accuracy: 0.8574
Adversarial accuracy: 0.5369
Defended adversarial accuracy: 0.5705
Defense recovery rate: 0.1050

This means defensive randomization improved adversarial accuracy from 53.69% to 57.05%.

That is a small improvement. It recovered 21 out of 200 successful attacks.

Conclusion: defensive randomization helped a little, but it was not strong enough.

7. Adversarial Training Result

Adversarial training was our stronger defense.

Instead of only training the model on clean images, we trained it on a mixture of:

- Clean X-ray images.
- FGSM-attacked X-ray images.

This teaches the model to become more robust against the attack.

The adversarially trained model got:

Clean accuracy: 0.8590
Adversarial accuracy: 0.7404
Standard attack success rate: 0.1381

Compared with the baseline:

Baseline clean accuracy: 0.8574
Adversarial model clean accuracy: 0.8590

Baseline adversarial accuracy: 0.5369
Adversarial model adversarial accuracy: 0.7404

Baseline attack success rate: 0.3738
Adversarial model attack success rate: 0.1381

This is a strong result.

Adversarial training increased adversarial accuracy by about 20.35 percentage points and reduced attack success rate from 37.38% to 13.81%, while keeping clean accuracy almost the same.

8. Final Interpretation

The project now demonstrates the full cybersecurity workflow:

1. Build a working cloud-style medical diagnosis model.
2. Show that the model performs well on clean X-ray images.
3. Attack the model using FGSM adversarial examples.
4. Show that the attack significantly reduces performance.
5. Try a simple defense, defensive randomization, and show that it only slightly helps.
6. Try a stronger defense, adversarial training, and show that it substantially improves robustness.

The main takeaway is:

The baseline chest X-ray classifier is vulnerable to adversarial attacks, especially for NORMAL images. Defensive randomization provides limited protection, but adversarial training significantly improves robustness while preserving clean accuracy.

9. Report-Ready Summary

A baseline ResNet18 chest X-ray classifier achieved 85.74% clean test accuracy. However, under an FGSM adversarial attack with epsilon 0.01, adversarial accuracy dropped to 53.69%, and the standard attack success rate was 37.38%. The attack was especially effective against NORMAL images, where 98.65% of clean-correct examples were successfully flipped.

A lightweight defensive randomization method slightly improved adversarial accuracy to 57.05%, but only recovered 10.5% of successful attacks. In contrast, adversarial training provided a much stronger defense. The adversarially trained model achieved 85.90% clean accuracy and 74.04% adversarial accuracy, reducing the standard attack success rate to 13.81%. These results show that adversarial training substantially improved robustness without significantly reducing normal diagnostic performance.
